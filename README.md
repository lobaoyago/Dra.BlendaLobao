
Dra. Blenda Lobão — Site Institucional

Landing page de alta conversão para a Dra. Blenda Lobão, cirurgiã-dentista especialista em harmonização orofacial em Salvador, BA.

Sobre o Projeto
Site institucional desenvolvido para apresentar os serviços de harmonização facial, preenchimento com ácido hialurônico, bioestimuladores, toxina botulínica e procedimentos especializados como rinoplastia, perfiloplastia e preenchimento labial. O projeto foi pensado para transmitir credibilidade, segurança e naturalidade — pilares da marca.

Funcionalidades
- Hero Section com imagem otimizada e CTA direto para WhatsApp e Instagram
- Seção "Sobre" com diferenciais da clínica
- Procedimentos e Tratamentos — grid com 9 procedimentos oferecidos
- Carrossel Antes/Depois interativo com toggle, navegação, lightbox em tela cheia e pré-carregamento de imagens para transição instantânea
- Casos Especializados — seções dedicadas a Rinoplastia, Perfiloplastia e Preenchimento Labial
- Depoimentos de Pacientes — grid scrollável com avaliações reais
- Footer com contato, localização e redes sociais
- SEO completo — meta tags, OpenGraph, Twitter Cards, schema.org (JSON-LD), canonical URL e sitemap
- Design responsivo — otimizado para mobile, tablet e desktop
- Imagens otimizadas — formato WebP com fallback JPG, lazy loading estratégico e compressão otimizada

Tecnologias
- React 18 + TypeScript
- Vite — build tool ultrarrápida
- Tailwind CSS — estilização utilitária com design system customizado
- shadcn/ui — componentes de UI acessíveis e reutilizáveis
- React Router DOM — roteamento SPA
- Lucide React — ícones modernos e consistentes

Design
Paleta de cores baseada em tons de bordô e vermelho profundo (`#640002`), transmitindo sofisticação e calor. Tipografia com Playfair Display (títulos) e Inter (corpo), criando contraste elegante entre clássico e moderno.
